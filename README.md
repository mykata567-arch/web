# 随机塔防 V0.2

下载仓库后，用浏览器打开 `index.html` 即可游玩；无需安装依赖或构建。也可用任意静态网站服务托管。本项目没有后端或存档，刷新会重新开始。

## 操作

- 开局免费三选一，然后点击开始下一波。共 20 波，每 5 波包含 Boss。
- 波次 1、3、5、8、11、14、17 结束后获得免费选择。
- 战斗间隙可花 50 金币招募一次，从最多三个随机角色中选择一个。打开招募即扣费，必须完成选择，不提供重抽。
- 新角色放入空塔位，重复角色升一星，最高五星。五星角色不进入候选池；候选不足三个时显示实际数量。全部满星时付费招募禁用，免费选择改为 50 金币。
- 点击塔查看属性、技能和射程圈。移动免费，点击绿色空塔位完成，底部按钮可取消；移动保留星级和冷却。
- 摧毁需再次确认，不返还金币；空位可用于后续招募。移动和摧毁可在战斗中使用。

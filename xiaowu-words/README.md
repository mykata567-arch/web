# 小五易错字 V0.1 · 家庭共用版

爸爸、妈妈、外婆各用自己的微信账号，通过家庭邀请码共用一本易错字本。爸爸录入后，妈妈重新打开或下拉刷新即可读取；外婆完成听写后，其他家人读取同一份云端复习状态。

**交付状态：源代码与自动测试已完成，尚未在微信开发者工具、真实云环境和三部手机上验收。不能将自动测试通过当作真实云端验收通过。**

## 第一版范围

- 两个主要页面：错字本、听写复习。家庭、录入和字详情作为辅助页。
- 词语拆字勾选，重复字合并并累计出错次数；编辑提示词语、删除错字。
- 词语挖空，例如 `山（　）`；点击看答案，再选择“会了”或“还不会”。
- 首次录入次日复习；连续答对依次间隔3、7、14天，第四次答对阶段性掌握；答错归零，次日再复习。
- 家庭创建、邀请码加入、成员共同维护，所有正式数据存于微信云数据库。
- 同一个操作重试不重复计数；不同成员同时复习同一个旧版本，只有先提交者成功。
- 可主动导入25字样本；“顶”计2次错误，其他字各1次，首次日期为2026-10-25。其他家庭不会自动收到样本。

不包含AI、语音、识字、收费、游戏化、多孩子或商业化功能。每个微信账号在V0.1只加入一个家庭，暂不提供换家庭和成员移除；需要恢复时由开发者协助处理云端数据。邀请码7天有效、最多6位家人，创建者可以更新邀请码。所有成员均可增改删和复习。

修改错字目前指修改该字的提示词语；若汉字本身录错，请删除后重新添加。删除从所有成员的字本和复习任务中移除，后台保留历史；重新录入同字时沿用历史并重新安排复习。

## 从下载到运行

需要：微信小程序AppID、与该小程序关联的微信云开发环境、微信开发者工具。代码使用**传统文档型云数据库**，不是PG/MySQL模式。游客AppID只作为源码占位符，不能完成家庭云共享。

1. 下载源码，进入 `xiaowu-words` 文件夹。电脑安装 Node.js 18 或更新版本。
2. 可先执行下面的本地验证，不需要安装任何前端依赖：

   ```sh
   npm run verify
   ```

3. 运行配置工具，按提示填写AppID与环境ID。这里不需要AppSecret或其他密钥：

   ```sh
   node scripts/configure.cjs
   ```

   工具在本机生成 `.local-project/`，里面是配置好的项目。原始代码保持占位符，生成目录已被git忽略。也可使用 `--appid` 和 `--env` 参数。每次更新源码后重新运行配置工具，再重新部署有变化的函数。

4. 在微信开发者工具“导入项目”，选择 **`xiaowu-words/.local-project`**，不要选 `miniprogram/`，也不要用浏览器打开。选择自己的小程序AppID。
5. 在开发者工具打开“云开发”，选择与配置一致的环境，完成下一节的数据库配置。
6. 对 `cloudfunctions/initUser`、`wordRecords`、`reviewRecords` 分别选择“上传并部署：云端安装依赖”。只部署这三个目录，不要把 `_shared` 当成第四个函数。选择控制台支持的 Node.js 18 或更新运行时，并把各函数超时设为30秒。
7. 点击“编译”。首次打开选择创建家庭，填写字本名和自己的称呼；回到空字本点击“导入小五现有的25个易错字”。
8. 进入“家庭”复制邀请码。将妈妈、外婆设为这个小程序的体验成员，上传体验版，并让两人用**各自微信账号打开同一体验版**，填写称呼和邀请码。后台入口名称以微信实际控制台为准。

新录入的字明天才到期。25字样本从2026-10-26起可以直接测试复习，之后导入会显示为逾期待复习；下次间隔按实际复习日计算。日期以云函数的北京时间为准，修改手机时间不能改变云端复习计划。

## 数据库配置

在传统文档型云数据库中建立以下7个集合：

```text
users
families
children
invites
words
reviews
operations
```

对**每一个集合**设置“仅管理员可读写”，或在自定义权限中填入 `database/permissions.json`：

```json
{ "read": false, "write": false }
```

小程序不直接读写数据库，全部经云函数访问。云函数每次读取服务端微信身份，再校验该身份是否属于目标家庭。不要为方便测试改成所有人可读写。学习记录、成员称呼和邀请码不能提交到GitHub。

按 `database/indexes.json` 创建普通、非唯一的联合索引，字段顺序必须一致：

| 集合 | 字段顺序 |
| --- | --- |
| words | familyId升序、childId升序、id升序 |
| reviews | familyId升序、childId升序、wordId升序、createdAt降序、id降序 |
| reviews | familyId升序、childId升序、date升序、type升序、id升序 |

`indexes.json` 是配置清单，不是自动部署脚本。等待索引创建完成后再试。

三个云函数只供微信小程序调用。不要给这些函数添加HTTP、Web匿名入口、定时器或其他调用渠道；入口会拒绝非 `wx_client` / `wx_devtools` 来源。SDK的微信上下文必须在每次请求内读取，不能全局缓存。

## 三人验收

完整步骤和未验证项目见 [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md)。最低验收需要三种真实微信身份，不能用同一微信账号换手机代替。

1. 爸爸创建家庭、导入样本，并另外录入一个样本以外的字，例如“读书”的“读”。
2. 妈妈和外婆分别加入同一家庭，确认都能看到“读”和相同错误次数；次日确认进入待复习。
3. 外婆完成一个到期字的听写；父母重新打开或下拉刷新，确认阶段、复习日期和历史一致。
4. 两位家长同时打开同一个到期字，先后提交不同判断：后提交者应看到冲突提示，复习次数只能增加1。
5. 另一位未被邀请的测试账号即使知道字ID，也不能读取、修改、删除或复习该字。具体控制台验证方法见验收文档。

界面采用“打开页面或下拉刷新时同步”，未实现持续推送。家人在另一个手机操作时，当前停留的页面不会自行闪动更新；旧页面提交时仍会校验云端版本。

## 目录与开发

```text
xiaowu-words/
  miniprogram/              微信原生页面与前端云函数调用
    pages/words/            主要页面1：家庭错字本
    pages/review/           主要页面2：听写复习
    pages/family/           创建、加入、邀请码
    pages/add/              录入错字
    pages/detail/           编辑、删除和复习历史
    domain/                 复习规则与服务端业务逻辑源文件
    services/cloud-api.js   云调用、未确认请求重试
  cloudfunctions/
    initUser/               身份与家庭
    wordRecords/            字本增改删与样本导入
    reviewRecords/          复习与历史
    _shared/                仅用于生成三个独立部署包
  seed/xiaowu-25.json        不含身份信息的25字样本
  database/                 集合、权限和索引配置清单
  scripts/                  打包、检查、本机配置
  tests/                    Node.js测试；内存存储仅用于测试
```

云函数各自携带自己的 `_shared/` 文件，不依赖上传目录外的文件。修改 `miniprogram/domain/` 或云端共享文件后，运行 `npm run build:cloud`；不要单独修改三个生成副本。修改规则从 `miniprogram/domain/rules.js` 开始，随后重新配置本机项目并部署三个函数。

`operations` 保存每次请求的幂等回执；不应随意删除，避免网络重试重复计数。`words.version` 防止两位家长用旧页面覆盖新结果；字状态与复习历史在同一数据库事务内写入。没有GitHub实时数据同步，也没有本地字本降级。

本地只保存尚未确认的操作内容和请求标识，成功确认后删除。断网时提示重试；重开应用会先向云端确认上次操作。已确认的记录不依赖当前设备缓存。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| 提示填写AppID或环境ID | 是否导入配置后的 `.local-project`，不是带占位符的源码目录 |
| 提示云端暂未完成操作 | 检查7个集合是否齐全、索引是否完成、函数日志里的错误码；SDK依赖是否安装 |
| 提示请从微信小程序访问 | 从小程序实际界面调用，不能用无微信身份的云控制台事件测试冒充用户 |
| 家人看不到字 | 是否打开相同AppID/环境的体验版、加入同一家庭；下拉刷新 |
| 邀请码失效 | 创建者在家庭页更新邀请码；已经加入的家人不用重新加入 |
| 新录入的字今天不能练习 | 按规则首次安排在次日，避免把刚抄过当作已掌握 |
| 同一个字提交失败 | 家人可能已复习、修改或删除；刷新任务读取最新版本 |

# 小五易错字 · CloudBase 网页版 V0.1.1

用于爸爸、妈妈、外婆共用一本家庭易错字本。这个独立目录面向腾讯云 CloudBase PostgreSQL 环境；原有 Sites 网站与其他项目不受影响。

## 当前状态

- 已实现：25字样本显式导入、错字新增/词语修改/删除、同字错误累计、挖空听写、查看答案、复习历史、3/7/14天复习规则、家庭邀请和设备找回。
- 创建者通过部署时设置的家庭管理码创建/找回；其他家人用16位邀请码加入。无需 ChatGPT 登录。每台设备获得独立凭证。
- 一个部署服务一个家庭。家庭管理码仅授权创建者；它与给家人的邀请码不同。改管理码后仍能找回原字本。
- 已通过：生产前端构建，15项自动测试（领域规则、真实嵌入式 PostgreSQL 的迁移/权限/CAS、模拟 CloudBase REST 的家庭共享流程、HTTP入口和重试）。
- 未验证：真实 CloudBase API Key、网关路由、默认域名访问、三个真实手机和中国大陆网络。测试中的 REST 请求由本地 PostgreSQL 协议测试器处理，不代表已经连通腾讯云。
- 当前执行环境的网络策略阻止腾讯云部署接口，因此尚未上传部署。不能把本目录或部署包描述为已上线。

## 控制台部署

现有上海地域、PostgreSQL 免费体验环境可以先用于测试。若任一步提示升级或付费，先核对套餐再继续。本项目不需要购买独立云服务器。

1. 在目标环境的 PostgreSQL 数据库「SQL 编辑器」执行 [sql/001-initialize.sql](sql/001-initialize.sql)。它只建表与权限，不导入学习数据，可重复执行。匿名角色及普通登录角色都没有家庭表/RPC权限。
2. 在该环境创建服务端 `API Key`（对应 `service_role`）。在腾讯云控制台内保存、配置，不要发到聊天、写入 GitHub 或放进前端。
3. 新建 **HTTP 云函数**，名称建议 `xiaowu-words`，运行时 **Node.js 22.21**。选择本地上传 `xiaowu-words-cloudbase-http.zip`。此包已包含构建好的页面、后台和可执行的 `scf_bootstrap`，不需要在线安装依赖。
4. 为该函数配置以下环境变量，然后保存部署：

   | 名称 | 值 |
   | --- | --- |
   | `CLOUDBASE_ENV_ID` | 你的环境ID |
   | `CLOUDBASE_APIKEY` | 第2步的服务端 API Key |
   | `FAMILY_SETUP_CODE` | 自行生成并保存的至少32字符随机家庭管理码 |
   | `APP_ORIGIN` | 获得访问地址后填写完整 HTTPS 来源，例如 `https://你的域名`，不含路径和末尾斜杠；初次可留空 |

   可在自己电脑的 Node.js 终端生成管理码：

   ```sh
   node -e "console.log(require('node:crypto').randomBytes(24).toString('hex'))"
   ```

5. 为这个 HTTP 函数配置外网访问，网关路径为 `/`，允许访客到达这个函数。应用内部会校验家庭凭证/管理码。只开放此函数入口，不要开放数据库的匿名读写权限。不要覆盖已有其他项目的根路径路由。
6. 打开 `https://访问域名/api/health`，应显示 `{"ok":true,"version":"0.1.1"}`；再打开根地址。创建时勾选导入25字样本，由创建者操作一次即可。

默认域名仅用于开发测试，可能先出现腾讯云访问提示页，不能据此承诺正式运营稳定性。正式域名、备案和套餐能力以腾讯云当前要求为准。

配置后日常使用只需要手机打开链接。邀请家人时私下发送网站地址和邀请码。

## 实机验收

1. 爸爸创建设备入口、导入25字；检查「顶」2次，其余各1次，不包含「小」「五」「山」。
2. 妈妈、外婆分别用自己的手机和称呼加入，核对三个人看见同一本字本。
3. 爸爸添加错字；妈妈刷新后看见。新错误次日复习，不回拨服务器时间做正式数据测试。
4. 外婆完成一个到期字的听写；爸爸、妈妈刷新后看到同一复习结果和下次日期。
5. 两台设备同时复习同一旧版本，后一份旧结果应被拒绝并刷新，不重复计数。断网后重试原操作也不重复计数。
6. 创建者换设备用管理码找回；其他家人用邀请码重新加入。核对他人不能凭猜测的字本ID读到学习数据。

旧 Sites 网站若已有新增错字/复习记录，本包不会自动复制。切换前需另行导出并校验导入结果，旧网站暂时保留。不要用25字样本覆盖真实学习历史。

## 本地开发和打包

开发需要 Node.js 22.21 或更新版本，自动测试在 Node.js 24.22.1 执行。

```sh
npm ci
npm run build
npm test
npm run package
```

生成 `release/xiaowu-words-cloudbase-http.zip`，只包含运行所需的文件，无密钥和用户数据。源码不含真实云环境ID，配置示例在 `.env.example`。

本地后台可用 `node --env-file=.env server.mjs`，前端开发用 `npm run dev`（将 `/api` 代理到本地9000端口）。源码启动优先读取 `dist/public`，发布包读取根目录 `public`。没有有效云配置时，页面可打开，但保存数据会明确报配置未完成，不用本地数据冒充同步。

## 数据处理

- 云函数通过服务端 HTTP API 访问 PostgreSQL。前端只调用本应用接口，不携带数据库密钥。
- `xw_wordbooks` 一行保存这个家庭的完整状态；比较 `revision` 后原子更新，错字、历史和幂等回执一起提交。适合当前小家庭规模，不是面向大量公开用户的结构。
- 请求使用 `X-Family-Token`，避免与 CloudBase 网关自身的 `Authorization` 冲突。前端持久化的是设备凭证及待确认的普通操作；管理码重试只暂存在内存。
- 时区按北京时间，过期任务按实际复习日重新排期。默认每轮10字。
- 家庭数据与游戏数据使用不同数据表、接口和访问边界；本目录没有接入其他游戏。
- 网页到小程序仍需接入微信身份、API调用及界面适配，不能直接把此网页包当作小程序包上传。

官方参考：[PG接入](https://docs.cloudbase.net/database/postgresql/connecting-to-postgresql)、[HTTP云函数](https://docs.cloudbase.net/cloud-function/quickstart/httpfunc/nodejs)、[网关访问](https://docs.cloudbase.net/service/access-cloud-function)。

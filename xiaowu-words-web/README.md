# 小五易错字 · 网页版 V0.1

手机打开网站即可使用的家庭易错字本。两个主要页面：错字本与听写复习；录入、详情及家庭邀请使用辅助弹窗。现有微信原生小程序另行保留。

## 使用

创建者第一次用ChatGPT登录以便换设备找回，创建家庭时可勾选导入25个初始易错字。默认词语按2026-10-25的匿名样本；顶计2次，其余各1次。样本在显式创建/导入操作中写入，不在数据库迁移中植入。

创建者在“我的家庭”复制邀请码，将网站链接和邀请码私下给家人。家人填写自己的称呼即可加入，无需ChatGPT账号；这个入口授予家庭字本的读取、增改删和复习权限。请勿公开邀请码。邀请码有效7天，创建者可更新，旧码立即失效。其他成员不能读取或更新邀请码。

当前设备记住的是成员访问凭证，正式学习记录始终保存在服务器数据库。清除浏览器数据后，创建者可以通过原ChatGPT账号找回，家人可使用新邀请码再次加入。更换设备不会创建新的独立字本。相同称呼的普通成员再次加入会沿用该成员；所有普通成员的字本操作权限相同，称呼不用于验证真实身份。V0.1不提供复杂账号管理或成员移除功能。

## 功能

- 字本总数、今日待复习、阶段性掌握；汉字/词语搜索和全部/待复习/掌握筛选。
- 输入词语再勾选目标汉字；重复字合并并按不同词语累计错误次数。
- 编辑对应词语；汉字本身输入错误时删除后重录。删除为归档：不再参与任务，再录入时保留历史。
- 词语挖空、点击看答案、家长选择会了/还不会；每轮最多10字，可继续下一轮。
- 次日首次复习，连续正确依次3、7、14天；第四次连续正确阶段性掌握；任意错误次日重来，已掌握后出错可重新激活。
- 每次复习保存结果、前后阶段、日期及陪练称呼。
- 重新打开/点击刷新读取家人最新记录；旧页面提交会校验字版本。
- 请求回执与待确认操作重试避免重复累计；同一字的并发判断只有一个被接受。

## 数据与未来小程序接入

网页版使用Sites托管的Cloudflare D1，**不是微信云开发数据库**。首次上线时平台自动提供DB绑定和执行结构迁移，无需先配置微信AppID。原小程序当前尚未连接此数据库。

`lib/shared/`保留从小程序复用的复习规则、日期及字记录逻辑；`lib/shared/seed.json`保留相同的25字样本。家庭具有独立UUID，记录字段保留character、phrases、errorCount、firstRecordedDate、lastErrorDate、streak、mastered、nextReviewDate及version。后续小程序需要适配界面、微信身份与家庭关联，并选择通过受保护的服务端API访问同一字本，或将这些结构迁移至微信云开发。数据不会仅存在浏览器，但网页账号与微信身份不会自动等同。

## 服务端结构

`app/api/book/route.ts`只接收同源写操作，使用平台注入身份创建/找回字本；普通成员通过邀请获得限定于一个家庭的访问凭证。服务器仅存成员密钥摘要，不将原始凭证或邀请码写入公开源代码。幂等回执包含初次授权结果以支持网络结果丢失后的恢复，只能通过同一受授权操作取回。`GET /api/book`无成员凭证时不返回学习记录。

`lib/book-service.mjs`以D1的一行JSON保存一个家庭的成员、字记录、复习历史和请求回执。每次修改用数据库revision比较更新，冲突重新读取并验证，字状态与对应历史一起原子提交。D1中另有邀请尝试计数表；邀请码查找使用独立唯一索引。

不要将`.wrangler/`、`.sites-runtime/`、浏览器凭证、数据库转储或真实学习记录推送到代码仓库。生产迁移只建立结构；测试样本在本地单独注入，不能混入生产迁移。

## 开发与验证

Node.js 22.13以上（测试的node:sqlite需要支持该内置模块的Node版本）。使用项目锁定的pnpm依赖。保留Sites的Vite/Worker集成，部署清单在`.openai/hosting.json`。

```sh
npm test
npm run typecheck
npm run build
```

修改`db/schema.ts`后执行`npm run db:generate`，检查生成的结构SQL并提交；已应用迁移保持不变。发布自动应用生产迁移。本地需要单独按starter文档使用Wrangler将SQL应用到本地DB。

验证情况：

- 8项自动测试通过：25字、3个独立成员凭证共享、SQL并发与重复请求、跨家庭隔离、修改删除与恢复、3/7/14天规则、邀请码及创建者找回、北京时间跨日。
- TypeScript检查与生产构建通过。
- 浏览器预览实际检查：加入家庭、读取样本、录入“读书”的“读”、听写挖空与答案、会了后保存并刷新看到下次日期。
- 自动测试使用SQLite执行真实SQL；浏览器预览使用本地D1模拟环境。这些不等同于爸爸妈妈外婆在三部真实手机完成验收。
- 生产网站使用独立D1；首次打开由用户建立自己的家庭。上线后仍应检查三部实际手机的访问、联网同步和一至两周任务节奏。

不包含语音、AI、识字、收费、奖励游戏、复杂图表或多学科。
